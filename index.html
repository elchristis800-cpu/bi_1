02 — DEL ORIGEN AL ANÁLISIS

El proceso ETL

Una ruta confiable para llevar datos desde sus fuentes hasta un formato listo para consultar.

01

EXTRACT

Extraer

Recopila datos de las fuentes que los generan: sistemas de ventas, archivos CSV, APIs o sensores.

EjemploDescargar ventas diarias del ERP y resultados de partidos.
02

TRANSFORM

Transformar

Limpia, estandariza y combina para que los datos sean consistentes y comparables.

EjemploUnificar nombres de equipos y corregir fechas duplicadas.
03

LOAD

Cargar

Guarda el resultado en un destino preparado para consultas, reportes y dashboards.

EjemploPublicar una tabla validada en el almacén de datos.

Buenas prácticas

Documentar fuentes y reglas · validar calidad en cada etapa · conservar trazabilidad · automatizar cargas repetibles.

Errores comunes

Ignorar valores nulos · mezclar unidades o zonas horarias · duplicar registros · cargar sin comprobar totales.
